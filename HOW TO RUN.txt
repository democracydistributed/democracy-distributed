Node is now installed on your machine (v24 LTS), so a fresh terminal will have node/npm on the PATH. 

From any new PowerShell or terminal window:

cd "C:\Users\ajaym\Documents\Claude\Projects\Democracy Distributed\democracy-distributed-next"
npm install        # only needed the first time (already done)
npm run dev
Then open your browser to:

http://localhost:3000 — uses the live gateway data
http://localhost:3000/?org=toronto — bundled City of Toronto demo data (works offline; good if the gateway is unreachable)
http://localhost:3000/?orgId=<id> — a specific org by id
Press Ctrl+C in the terminal to stop it.

Other commands
npm run build      # production build
npm start          # serve the production build (run build first)
npm run lint       # lint
Two gotchas
"npm is not recognized" → that terminal opened before Node was installed. Just close it and open a new one (the installer added Node to PATH; existing windows don't pick it up retroactively).
The dev server I started earlier may still be running on port 3000. If npm run dev says the port's in use, either use the new port it offers, or kill the old one:
Get-NetTCPConnection -LocalPort 3000 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
